# Project 03: Gym & Fitness Center Membership Subscription System

### 🏋️‍♂️ Fitness Platform

A robust web application designed to manage gym memberships, handle secure subscription transactions, and provide administrators with actionable dashboard statistics.

---

## 🚀 Core Features & Transactions

* **Plan Selection:** Support for multiple tier configurations, including flexible Monthly and Annual membership options.
* **Personal Trainer Addon:** Dynamic shopping cart integration specifically for selecting and applying personal trainer add-ons to a subscription.
* **Payment Gateway Integration:** Secure, end-to-end checkout system handling payment authorization and digital invoices.
* **Subscription Renewal:** Automated workflow facilitating timely subscription renewal payments.

---

## 📊 Dashboard Reports & Analytics

* **Expiring Memberships:** Real-time administrative tracking highlighting memberships expiring within the next 7 days.
* **Payment Collection Breakdown:** Comprehensive analytical charts displaying financial streams and collection history.
* **Member Statistics:** High-level metrics contrasting active vs. inactive members to track user retention.

---

## 💻 Tech & Syllabus Stack

The application is built leveraging enterprise-level software design patterns:

* **Architecture:** Divided into distinct **Areas** for optimized separation of concerns (`Admin` / `Member`).
* **UI/UX:** Structured with a unified **Custom Master Layout** for seamless, responsive navigation.
* **Data Processing:** Driven by intense **LINQ Aggregation** optimization for reporting datasets.
* **State Management:** Utilizes **TempData** structures for reliable short-lived data caching across controllers.
